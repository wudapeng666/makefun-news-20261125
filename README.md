A deterministic editorial poster summarizing four world-news developments published or reported on 25 November 2026: reported US tariff expansion, a Ukrainian strike on Russian vessels near Benghazi, the end of a supermarket hostage siege in Colombia, and Amnesty International's call for an ICC genocide inquiry concerning reproductive harm in Gaza.

The artwork is an original vector-style layout. It uses no third-party photographs and no network resources.

## Run it

```sh
mkdir -p out
MAKEFUN_OUTPUT_DIR=out node main.ts
```

The program copies `entry.png` to `out/entry.png`. The committed image is 1024 × 1024, below 1 MiB, and deterministic.
